# Reconnaissance and Scanning

## Objective

Gather information about the target system and identify running services.

## Tools Used

- Nmap
- Netdiscover

## Steps Performed

### Host Discovery

Identify available systems in the network.

### Port Scanning

Determine open ports and services.

### Service Enumeration

Identify versions of running services.

## Findings

| Port | Service |
|--------|---------|
| 21 | FTP |
| 22 | SSH |
| 80 | HTTP |
| 139 | NetBIOS |
| 445 | SMB |
